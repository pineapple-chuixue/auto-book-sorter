# 📚 AI Book Sorter (AI 电子书半自动归类流水线)

大道至简。这是一个轻量级、零成本、无门槛的本地电子书分类工具。
无需繁琐的 API Key 配置，无需折腾本地大模型部署。利用本地脚本 + 网页版大语言模型（如 ChatGPT / DeepSeek / Kimi）的推理能力，帮你瞬间将杂乱无章的电子书按多级目录整理得井井有条。

## ✨ 核心特性

- **高度解耦**：所有路径配置抽离于 `config.json`，开箱即用。
- **正则预清洗**：自动剔除 Z-Library 等杂乱的文件名后缀，仅提取纯净书名。
- **无缝衔接**：自动生成包含最新版自定义书架分类图谱的 AI Prompt ，并写入系统剪贴板（Windows），即粘即用。
- **字典自生长**：AI 若生成了全新的分类路径，脚本会自动按分类建文件夹归档收录。
- **阅后即焚**：归档完成后自动清理 Inbox 和临时 JSON 映射文件，保持目录整洁。

## 🚀 快速开始

### 1. 基础配置
修改 `config.json` 中的路径为你电脑上的物理路径：
- `inbox_dir`: 你的日常收件箱（新下载的书丢这里）
- `library_dir`: 你整理好的主书库（脚本会自动在这里建多级文件夹，首次使用可为空）
- `categories_file`: 本地分类字典缓存（无需手动创建）

### 2. 日常归档流水线（极简两步走）

平时下载了新书，直接扔进配置好的 `inbox_dir` 文件夹，然后分两步执行：

#### [步骤一] 生成提示词：
```bash
python step1_generate_prompt.py
```
**做的事情**：自动扫描 Inbox 下的新书提取纯净书名，并结合当前 `library_dir` 中的真实分类目录生成提示词，自动复制到剪贴板。

**操作要求**：打开你喜欢的网页版 AI（例如 DeepSeek），直接 Ctrl+V 粘贴对话，**将 AI 返回的 JSON 数组原样复制，并保存到本目录下的 `inbox_categorized.json`**（对应 config.json 里的 `ai_output` 字段）。

---

#### [步骤二] 移动归档：
```bash
python step2_sort_books.py
```
**做的事情**：脚本根据保存的 JSON 结果，将 `inbox_dir` 的书籍**移动**到主书架 `library_dir` 对应的长效细分目录中。如果有新创建的分类会自动建文件夹并刷新字典图谱记录。
完成后自动清理 `inbox_dir` 的临时映射缓存文件，保持空间整洁！

## 🛠️ 环境要求
- **Python 3.6+**
- 仅使用了 Python 标准库 (`json`, `re`, `shutil`, `subprocess`, `pathlib`)，**无需 pip install 任何第三方包**。
